# Iconography

## 브랜드 아이콘 색상과 이름 변경

Lucide는 [Icon 구현](https://github.com/lucide-icons/lucide/blob/main/packages/lucide-react/src/Icon.ts)과 [기본 속성](https://github.com/lucide-icons/lucide/blob/main/packages/shared/src/build/defaultAttributes.ts)에서 `currentColor`를 stroke에 사용합니다. 채워진 GitHub·LinkedIn 브랜드 아이콘은 기존 SVG의 `fill="currentColor"`를 사용해 부모 텍스트 색상을 따릅니다. 아이콘이 배경이나 테마를 자동으로 감지하지는 않습니다. 부모에 테마별 색상을 지정하거나 `Icon`에 `tone="neutral"`을 지정하세요.

| 삭제된 이름                     | 변경할 이름 |
| ------------------------------- | ----------- |
| `GithubLight`, `GithubDark`     | `GitHub`    |
| `LinkedInLight`, `LinkedInDark` | `LinkedIn`  |

이전 이름은 공개 아이콘 목록에서 제거되었으며 별칭으로 남아 있지 않습니다.

```tsx
<>
  <Icon name="GitHub" tone="neutral" aria-label="GitHub" />
  <Icon name="LinkedIn" tone="neutral" aria-label="LinkedIn" />
</>
```
